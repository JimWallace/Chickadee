# Handle review data

The review tool (`../review.mjs`) and `AvatarHandleTests` read these files.
One entry per line. A line that starts with `#` is a comment. Matching ignores
case.

| File | What it holds | Source |
|---|---|---|
| `first-names.txt` | First names | Generated by `../build-names.mjs` (see below) |
| `surnames.txt` | Common surnames | Generated by `../build-names.mjs` (see below) |
| `skin-tone.txt` | Words used for human skin, and the plain colour words that name races | Hand-curated |
| `traits.txt` | Words that describe a person | Hand-curated |
| `positive-traits.txt` | Traits from `traits.txt` that may stand before a scientist's name, and only there | Hand-curated |
| `slang.txt` | Words with a sexual, drug or crude slang meaning | Hand-curated |
| `testing.txt` | Words that read as a verdict on code | Hand-curated |
| `phrases.txt` | Two-word pairs that are brands, titles, places or idioms | Hand-curated |
| `substrings.txt` | Letter sequences that must not appear anywhere in a compound handle | Hand-curated |

Extend the hand-curated files when you find a gap. Do not remove a word from
them to make a list pass: change the list in `AvatarHandle+Words.swift` or
`AvatarHandle+Scientists.swift`. Add a word to `positive-traits.txt` only when
it names a positive part of character, never a mood, the body, the mind or
intelligence.

## Generated files

`first-names.txt` is the union of:

- **US Social Security Administration baby names**: every name in the top 1,000
  for either sex in any year from 1950 to 2008. Public domain (a US Government
  work). The SSA download (`https://www.ssa.gov/oact/babynames/names.zip`)
  refused the fetch, so the copy used is Hadley Wickham's extract of the same
  SSA data, `https://github.com/hadley/data-baby-names` (`baby-names.csv`,
  top 1,000 per sex per year, 1880 to 2008). Fetched 2026-09-30.
- **Ontario top baby names**: the top 500 per sex in any year from 1950 to 2024.
  Open Government Licence – Ontario.
  `https://data.ontario.ca/dataset/ontario-top-baby-names-female` and
  `https://data.ontario.ca/dataset/ontario-top-baby-names-male`. Fetched
  2026-09-30. This source covers the years after 2008 that the SSA extract
  does not.

`surnames.txt` is the top 1,000 surnames of the **US Census 2010**, public
domain,
`https://www2.census.gov/topics/genealogy/2010surnames/Names_2010Census_Top1000.xlsx`.
Fetched 2026-09-30.

To rebuild them, download the four files and run:

```sh
node Tools/handle-review/build-names.mjs baby-names.csv baby_names_-_female_.csv baby_names_-_male.csv Names_2010Census_Top1000.xlsx
```

The script needs `unzip` on the PATH to read the spreadsheet.
