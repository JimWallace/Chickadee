# Fix failed dependency updates (daily)

Goal: every Dependabot update that CI blocked is merged, or closed with a
recorded reason. Follow the rules in `Tools/maintenance/README.md`.

1. List the open issues labelled `dependency-update-failed`. If there are
   none, report "nothing to do" and stop.
2. For each issue, read the body and every comment.
   - If a comment says a person is handling it, or that it needs a
     maintainer decision, leave it and list it in the report.
   - If the linked Dependabot pull request is closed or merged, comment that
     the problem is gone. `dependency-health.yml` closes the issue.
3. Otherwise follow the issue's "Brief for an agent". Find the root cause in
   the failed job's full log, not its tail. Fix it with commits on the
   Dependabot branch. Never rewrite that branch's history or force-push.
   Committed vendored output is regenerated by
   `.github/workflows/dependabot-auto.yml`; read its header before you edit
   `Public/vendor`, `Public/jupyterlite` or the extension's labextension by
   hand.
4. If the new version cannot work here, add an `ignore` entry with the reason
   to `.github/dependabot.yml` in its own pull request (auto-merge on), close
   the Dependabot pull request with an explanation, and say so on the issue.
5. Check that auto-merge is on for each Dependabot pull request you fixed.
6. Comment on each issue you worked on: the root cause, the change, and the
   pull request.
