### Added

- **Mascot icon set.** Ten new chickadee illustrations covering the states the
  UI already has surfaces for: home, 404, 500, success, empty, studying,
  writing, achievement, grading and welcome. They live in `Assets/` as the
  source of truth; each is copied into `Public/images/` only when a surface
  starts using it, so nothing is served that nothing references. All are
  384x384 RGBA with a transparent background, matching the existing mascot.
