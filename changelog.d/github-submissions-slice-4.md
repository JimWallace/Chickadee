### Added

- **GitHub course repositories (slice 4 of docs/github-submissions.md).** A course can bind a GitHub organization on the new instructor page `/instructor/github`. Binding needs the GitHub App on the organization and an organization owner, which a GitHub authorization confirms; the token is revoked at once. An instructor then chooses a template repository per assignment. Each student makes their own private copy with *Make my repository*, is invited to it, and submits only from it. The page warns when the organization lets members fork private repositories, and can archive every course repository at the end of term. The App asks for the two extra permissions only when the admin ticks *Allow course repositories*. The design note gains a table of every item of data that reaches GitHub, for the privacy review. Nothing changes while no GitHub App is registered.
