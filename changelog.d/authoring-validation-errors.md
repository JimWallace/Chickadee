### Changed

- **Three more authoring validators throw a typed error, one case per rule.** `ManifestValidation`, `PatternKindHandler` and `NotebookCheckKindHandler` built 46 `Abort(.unprocessableEntity, reason:)` values with hand-written sentences, and imported Vapor for nothing else. They now throw `AuthoringValidationError`, whose description is the same sentence word for word and which leaves a route or an MCP tool as the same 422. The three files no longer import Vapor and leave the Utilities allowlist. `PatternFamilyValidator` and `PatternFamilyAuthoredGraph` still throw `Abort`, because their tests assert that type. This continues #1929.
