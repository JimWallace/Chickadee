### Changed

- **`Utilities/` holds pure code again, and a guard keeps it that way** (#1730). The database configuration and migration registry, the migration-namespace reconciler and the session driver move to `Bootstrap/`. The disk-usage helpers and the five pattern-family save files, which read or write the database, move to `Services/`. `BlockingWork` and `DatabaseErrorDetail` move to `Helpers/`, and `PollFragmentResponse` moves to `Routes/Web/`, its only callers. Five pure scanners and formatters move the other way, from `Services/` to `Utilities/`. `scripts/check-utilities-imports.sh` now fails when a file under `Utilities/` imports Vapor or a database module. Six validators that throw `Abort` may still import Vapor, and that list can only shrink. Nothing else changes.
