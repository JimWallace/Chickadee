### Added

- **Example activity: the Kestrel Chase.** `docs/examples/kestrel-chase/` is a class composite for a data science lab. Students locate three hops of one route from their own part of dealt-partition evidence: a daylight log (model inversion), noisy phone pings (robust estimation) and relay distances (nonlinear least squares). Each passing route map is added to the class map with the `sum` compositor. It includes a seeded case generator, a case checker, five tests including a decoy case, and starter and solution notebooks. Docs only.
