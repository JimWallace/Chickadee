### Removed

- **The runner's `--worker-secret` flag** (#2226), deprecated since #2220. It put the runner secret in the runner's command line, where every test script can read it from `/proc`, also inside the sandbox, and so sign worker API calls such as reporting its own result. Set `RUNNER_SHARED_SECRET` instead, or let the runner read the `.worker-secret` file. A runner still started with the flag now exits at once with an "unknown option" error, so check every runner's start command before upgrading. The server's own `--worker-secret` flag is unchanged.
