### Changed

- **One icon, one meaning.** Reset notebook to starter is now an eraser. Before,
  it was a counter-clockwise arrow that looked the same as Retest's circular
  arrows beside it. Other glyphs that carried two or more meanings now each say
  one thing:
  - Copy student link is the clipboard copy icon.
  - Duplicate and Clone course add a plus.
  - Leaderboard is a podium.
  - Remove from course, Leave course and Unlink no longer use the trash can.
  - Unarchive and Restore course are a box with an up arrow.
  - Refund slip day is an undo arrow.
  - New handle and Hatch a new bird are shuffle.
  - The graded-assignment tile is a clipboard with a tick, so the calendar with
    a tick means only a deadline extension.
  - Unpublished setups, notebooks, courses and Add staff member each get their
    own tile.
  - Diff against starter is a file with plus and minus lines.
