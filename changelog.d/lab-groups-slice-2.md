### Added

- **Lab groups (slice 2): per-group sessions.** A class activity can now run once per lab group (the edit page's "Run once per lab group" box, or `set_activity`'s `runsPerGroup`). Course staff start and end each group's session from the present page, which then shows a five-character join code. Students submit only while their session is open, and a student in another lab or in no group joins by typing the code at `/join`. See `docs/lab-groups.md`.
