### Added

- **Shared row components for the instructor redesign.** A ⋯ row menu, a `+ Add` menu shell and a state select (a dropdown with a coloured state dot) join the component vocabulary, with five new sprite icons. The ⋯ menu floats out of the table so the last row's menu is not clipped.
- **Popups close on an outside click or Escape.** Escape returns focus to the button that opened the popup. This applies to every existing popup as well.
- **One list-filter threshold.** `ListFilterPolicy.minimumRows` (8) now drives every Filter box that appears only on longer lists.
