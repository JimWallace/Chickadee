### Added

- **Notebook checks render in R for the data-frame family.**
  `data_frame_shape`, `data_frame_columns`, `data_frame_equality` and
  `series_equality` now generate `.R` test scripts, so an R assignment can
  assert on data frames the way a Python one does. A pandas DataFrame maps to a
  base-R `data.frame` — guarded with `is.data.frame`, so tibbles and
  `data.table`s pass too and no package is needed at grading time. R has no
  Series, so `series_equality` accepts a vector or a one-column frame against
  the same single-column expected CSV. Numeric columns compare within
  `rtol`/`atol`; other columns compare as text, so a factor and a character
  column holding the same labels agree. The `_expected_<id>.csv` sidecar is
  language-neutral and shared with the Python path. Python's generated bytes are
  unchanged, keeping every `spec_hash` and `TestSetupCache` key stable.

### Changed

- **Unsupported notebook-check kinds are refused for R assignments at save
  time.** `numeric_array_close`, `figure_count`, `cell_contains`,
  `function_exists`, `variable_exists` and `ast_structure` have no R renderer
  yet; saving one on an R assignment now fails with a message naming the
  supported kinds, instead of emitting a `.py` script the R suite could never
  run. See `docs/r-support.md` for what each of the six would need.
