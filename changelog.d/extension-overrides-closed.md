### Fixed

- **A per-student extension now reopens an assignment for that student no matter how it closed.** Granting an extension on an assignment that was *manually closed before its deadline* previously had no effect — the submission gate inferred instructor intent from close timing and refused to reopen it, locking the accommodated student out of submitting and editing. An active extension is now an explicit, decisive signal: the student may submit and edit regardless of the assignment-wide open/closed state (the only thing it still respects is a not-yet-reached open date). The "has an active extension" check is consolidated into one shared `studentHasActiveExtension` helper used by the submission gate, the student dashboard, and the dashboard visibility filter so the three can never drift, and the contract is pinned by an exhaustive invariant test.
