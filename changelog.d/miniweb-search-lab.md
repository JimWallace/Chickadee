### Added

- **A search-engine lab on a mini web.** `docs/examples/miniweb/` sketches an HLTH 230 unit on how the web works and how search began. It has a deterministic generator for a fictional 116-page web (URL to HTML, every normalization trap placed on purpose), a starter and solution notebook built from one source, six public tests that each grade only their own stage (normalize, extract links, crawl, graph, PageRank, search), and a script that checks the link farm lesson still holds.
