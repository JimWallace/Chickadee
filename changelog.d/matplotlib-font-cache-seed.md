### Fixed

- **A Python test no longer rebuilds matplotlib's font cache.** The sandbox gives each test script an empty home directory, so matplotlib found no font cache and parsed every font on the runner again in every test whose submission imports `matplotlib.pyplot`. It did that inside the test's time limit and wrote "Matplotlib is building the font cache" to the test's output. The runner image now builds the cache once, and the Python bootstrap copies it into the fresh home directory before the submission loads. A runner outside the image keeps the old behaviour, and a cache that does not match the installed matplotlib is rebuilt by matplotlib as before.
