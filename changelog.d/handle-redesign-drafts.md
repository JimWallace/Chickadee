### Added

- **Draft lists for a new class handle design.** `Tools/handle-review/drafts/` holds the data for three handle schemes: a positive disposition and a scientist ("Curious Noether"), a science noun and an agent ("Photon Navigator"), and a compound word ("Ionspark"). The scientist list has 436 people, 43% women and 34% from Europe. No code uses the drafts yet, so the handles that students see do not change. See `docs/student-avatars.md` §3.
