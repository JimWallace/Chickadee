### Added

- **Pattern families render in R.** All eight `PatternKind`s
  (`boundary_equality`, `approximate_equality`, `variable_equality`,
  `return_type_check`, `exception_expected`, `performance_threshold`,
  `stdout_equality`, `unordered_equality`) now generate `.R` test scripts, so an
  R assignment can use generated test families exactly like a Python one —
  including the per-student variants, whose values arrive via `_ck_inputs.R`.
  Generated R uses the injected runtime (`chickadee_load_student()`,
  `chickadee_require_fn()`, `chickadee_equal`, `chickadee_format`) so failure
  messages read the same in both languages. Python's generated bytes are
  untouched, keeping every `spec_hash` and `TestSetupCache` key stable.
- **Literal globals reach hand-authored `.R` tests.** A raw script's extension
  names its language, so save-time inlining emits `name = <pythonLiteral>` for
  `.py` and `name <- <rLiteral>` for `.R`; previously `.R` scripts were skipped
  and never saw the assignment's literal inputs.
- **R value-comparison helpers in the grading runtime** — `chickadee_format`,
  `chickadee_equal` (numerics compared by value, so `3L` satisfies an expected
  `3`), and `chickadee_unordered_equal`.

### Fixed

- **Stale generated files survived a language change.** The deletion diff listed
  a family's generated filenames for one language only, so the old-extension
  scripts were left in the test setup forever. It now lists every language.
