# Codebase Audit — July 2026 (v0.4.582)

A "make it right, make it fast" pass over the last two weeks of work
(~v0.4.560 → v0.4.582, since 2026-06-16). The window's churn concentrated in
five areas — BrightSpace/LEARN grade + roster sync, the #417 multi-course-roles
series, the MCP authoring surface, the Leaf web-route layer, and the
Worker/Core grading path — so the audit was run as six parallel sweeps
(the five above plus a cross-cutting pass on Sendable hygiene, TODO/dead-code
inventory, frontend JS, and doc drift).

Every finding cites `file:line` as of v0.4.582 and was verified against the
current tree (not just the diff). Findings are sized so each becomes one
issue/PR. **A GitHub issue has been filed for every work item below** —
issue numbers are noted inline. Work is queued for follow-up; nothing here is
applied.

This document is the companion to `docs/archive/audit-2026-06.md`. That audit's
dominant theme — *unfinished adoption* — has been **substantially worked off**
(see "June audit: what got fixed" at the end); the handful of its items still
open are re-filed here with current line numbers.

## Priority list (cross-cutting, ordered)

### P0 — correctness / security (do first)

1. **Cross-course secret-test / solution exposure via instructor-editor read
   loaders.** The write loaders scope to the resource's course; the *read*
   loaders don't authorize at all, so an active TA of course A can fetch course
   B's reference solution and secret tests by 6-char assignment ID. Same hole
   #417 Slice G closed on the API side, missed on the web editor.
   → **#1103**
2. **Path traversal in the new datasets route.** `DatasetSpec.file` is
   validated only non-empty, then used for `String(contentsOfFile:)` (read of
   any server-readable file incl. `.worker-secret`) and for two file writes on
   server + worker. The `safeScriptFilename` convention already exists to fix
   it. → **#1104**
3. **BrightSpace `clearGrade` sends the wrong HTTP verb.** It signs a Valence
   `DELETE` but the transport dispatches only PUT/GET, so it emits a GET — grade
   removal (#1075) can't work against real D2L, and the terminal 403 is silent
   and unrecoverable (clear rows are never re-queued). → **#1105**
4. **Worker leaks the per-job scratch copy on every prepare-phase failure.**
   The cleanup `defer` is registered after the acquiring call returns, so any
   throw in download/stage/normalize/make/helpers leaks a full test-setup dir.
   Disk-fill already took prod down once this window (b7ddbf1). → **#1106**
5. **Worker `make` step has no timeout and blocks a cooperative-pool thread.**
   Runs after the student submission is merged, so a hung `make` wedges a job
   slot indefinitely — the exact starvation `ScriptRunner` was hardened against.
   → **#1107**

### P1 — consistency & drift-prevention (correctness-adjacent)

6. **"Highest-grade-wins" is one helper + three inline copies**, and the
   per-student drilldown still shows the *old* worker-preferred grade — an
   instructor sees one number on the roster and a different one on the page they
   click through to. → **#1111**
7. **Route-walking authorization matrix test** so a new `/instructor` or
   `/courses` mutation can't forget the per-course gate (the class of miss that
   produced #1103). MCP already has this guard; the web side doesn't. → **#1112**
8. **Unify the course write-access policy** — web `requireCourseWriteAccess`
   and MCP `authorizeCourseWriteAccess` are hand-maintained twins with
   alternating implicit role-floor defaults, plus 2–4× redundant user
   re-resolution per write call. → **#1113**
9. **BrightSpace per-instructor connect/identity UI documented in the runbook
   doesn't exist** — three dead handlers and half the view context, computed on
   every page load. Decide: restore the panel or delete + update the doc.
   → **#1114**
10. **MCP close-on-edit + auto-retest isn't a guaranteed chokepoint** —
    `update_solution` hand-rolls the close and skips retest (contradicting its
    own doc comment); global-inputs tools are in neither contract list. → **#1115**
11. **Docs drift** — CLAUDE.md still describes the pre-#417 role model and
    stale counts (tools, pattern kinds, test files); `multi-course-roles.md` and
    `mcp-authoring-roadmap.md` contradict shipped reality. Every fresh agent
    session inherits these as ground truth. → **#1125**

### P2 — structure & duplication (maintenance load)

12. **Split `BrightSpaceGradeSyncService.swift` (1059 lines)** into
    grade-selection / clears / sweep, and adopt `PeriodicSweepMonitor` (its two

16. **Refactor `WebRoutes.index`** (445-line handler with a lint suppression)

17. **MCP: dedup `AdminMCPDispatcher`** (~150-line clone) and the hand-written

    → **#1121**
18. **Decompose `applyPatternFamilies`** (~660-line god function; renders every

19. **`submissionPage` re-fetches the same setup ~4× per request** (still open

20. **Finish the frontend JS consolidation** — `chickadee-ui` shared helpers,

## By subsystem

### BrightSpace / LEARN sync

The subsystem's *seams* are excellent — `BrightSpaceGrading` protocol with an
in-memory fake driving the real debounce/selection/caching logic; transport
helpers extracted pure and pinned by `BrightSpaceTransportTests`; clock-skew
learning with a single non-destructive retry; the `GradeOverrideHelpers`
"only clear what Chickadee pushed" safety gate. The problems are (a) one live
bug the test net doesn't reach — verb dispatch (#1105), (b) a documented
feature with no UI entry point (#1114), and (c) the file having absorbed every
new behavior this fortnight into one 1059-line unit with parameter-threaded
free functions (#1116) and three divergent identity maps (#1117).

### #417 multi-course roles

The chokepoint layering in `CourseAccessHelpers` is textbook, `CourseRole` as a
gapped `Comparable` reads like the policy it implements, migration hygiene is
careful, and `MCPAuthorizationCoverageTests` is a real structural guard. Two
gaps: the read path has no equivalent authorization (the #1103 exposure) and no
structural guard (#1112), and the write policy is expressed twice with drifting
floors (#1113). Naming has drifted (instructor-named gates that admit TAs) and
the design doc contradicts the shipped code (#1125, #1127).

### MCP surface

The shared tool harness is genuinely good: `ContentTool` + type-erasure +
registry give one decode/encode chokepoint, the authorization ladder encodes
the whole #417 policy in one file, errors are uniformly `MCPToolError`, and the
dispatcher's fail-closed write-auditing is well built. The issues are the parts
that grew *around* the harness: a cloned admin dispatcher and hand-written
schema literals (#1121), a close/retest chokepoint that's opt-in and already
diverging (#1115), and doc/prose sync that has no guard and is already stale
(#1125). `MCPOAuthRoutes.swift` is clean but oversized (#1122).

### Web route layer

Comment discipline here is unusually high — nearly every non-obvious decision
cites the issue/version that motivated it. `MaterializedValidationSubmission`
(move-only token preventing a save race by type) and `resolveStudentAssignmentAction`
(one preamble for seven handlers) are exemplary. The recurring smell is
copy-that-documents-itself-as-copy: the highest-grade rule (#1111), section
grouping / sort / loaders (#1118), the orphaned upload twin (#1119), and one
445-line handler (#1120).

### Worker / RunnerCore / Core

The June split left `RunnerDaemon+JobProcessing` as named single-purpose phase
helpers (it does *not* need decomposition); `TestSetupCache` and `ScriptRunner`
are model actors with their invariants written down; typed throws and
`@unchecked Sendable` hygiene are 100%; the Core/RunnerCore boundary is genuinely
Foundation-free and pinned by drift tests both sides. The defects are localized:
the datasets path traversal (#1104), the scratch leak (#1106), the untimed
`make` (#1107), and `applyPatternFamilies` as the one god-function that resisted
the split (#1123).

### Cross-cutting

`@unchecked Sendable` is 100% commented (36 sites); all 21 TODO/FIXME hits are
intentional instructor-facing template content, not code debt; the one `try!`
is a justified static regex; env-mutating suites correctly serialize. The June
audit's "unfinished adoption" theme is largely closed. Residuals: the frontend
JS consolidation stopped at `escapeHtml` (#1126), one `Issue.record`-to-skip and
one AppConfig bypass (#1129), and the doc drift (#1125).

## What's genuinely good (keep doing this)

- **Conventions turned into build failures.** `MCPAuthorizationCoverageTests`
  and `MCPInstructionsCatalogSyncTests` (source-scan / mention guards),
  `RuntimeSourceDriftTests` on both Swift and JS sides, the output-contract
  fixture pinning native vs wasm. The fix for several findings above is just
  "add one more test in this exact shape."
- **Invariants encoded in types, not comments** — `MaterializedValidationSubmission`,
  the gapped `CourseRole: Comparable`, `TestSetupCache`'s documented eviction race.
- **Typed throws and error taxonomy** in the worker (`ReporterError`,
  `JobPollerError` distinguishing decode from transport failure).
- **Comment discipline** — decisions cite the issue/version that motivated them,
  which made this whole audit fast.
