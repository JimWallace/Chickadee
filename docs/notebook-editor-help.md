# Notebook editor help

The notebook editor runs in your browser. It downloads a language kernel and
starts it on your device, so it needs a recent browser and enough free memory.
When the editor cannot start, the assignment page shows a notice or a panel.
This page tells you what each one means and what to do.

You can always submit without the editor: upload your notebook file
(`.ipynb`) with the file picker in the notice or the panel.

## The editor is slow to load

The notice "Editor slow to load" shows when the editor has not started after
35 seconds. The editor stays on the page, and it can still finish loading.
When it does, the notice goes away.

Older browsers, and devices with little memory such as some iPads, can take a
long time to start the editor, or cannot start it. Do one of these:

- Wait, or reload the page.
- Open the assignment on a laptop or desktop computer, in a recent version of
  Chrome or Firefox.
- Upload your `.ipynb` file with the file picker in the notice.

## Your browser ran low on memory

The kernel stopped because your browser reached a memory limit. This is
frequent on Safari, and on phones, tablets and computers with little memory.
Do one of these:

- Reload the page to try again.
- Open the assignment on a laptop or desktop computer, in Chrome or Firefox.
- Upload your `.ipynb` file with the file picker in the panel.

## The editor did not load

The editor did not start in your browser. Some browser settings stop it:

- a private or incognito window;
- a setting that blocks site data;
- a computer that an organization manages, which can turn off service workers
  or WebAssembly.

Do one of these:

- Upload your `.ipynb` file with the file picker in the panel.
- Use "reset the notebook editor" on the panel. It clears the editor's cached
  data in this browser so that the kernel can start again. Your submitted work
  is safe, and you stay logged in.
- Try a different browser, or a window that is not private.

## Ask for help

If the editor still does not load, ask your course staff for help. Open
"Diagnostic details" on the panel and copy its text into your message. The
text names the problem, your browser and your operating system.
